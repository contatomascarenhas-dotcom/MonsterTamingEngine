❓ Como usar
  1. 1. Banco: crie seus PETs (só nome e tipo), itens e personagens. Os golpes já vêm prontos.
  2. 2. Mapa: escolha um tile na paleta e toque no mapa para pintar. Use 🚩 Posição inicial para definir onde o herói começa.
  3. 3. Eventos: toque em ⚡ Evento, escolha a célula e monte os comandos. Use ▲▼ para a ordem e marque Transparente para esconder o evento.
  4. 4. Decisões: use 🔀 Condicional para criar um se/senão (item, PET, HP, chave ou variável) e ❓ Decisão para o jogador escolher. Chaves e variáveis são criadas pelos comandos 🚩 e 🔢.
  5. 5. Transporte: no evento, escolha o comando 🚪 e clique no mini mapa para dizer onde o herói aparece.
  6. 6. Jogar: use o joystick para andar. O A interage com eventos e o B abre o menu (salvar, itens, bestiário e time). Use 🧪 Poção no menu ou na batalha para curar.
💡 Dica: no teclado, use as setas para andar, Z como A e X como B. Imagens enviadas do PC têm o fundo preto removido automaticamente.
